# Wireframes & Journey Maps

## 1. Unified Conversation Timeline (UX Concept)

**Goal:** Provide the agent with a single, visually organized view of every touchpoint the customer has had with the brand, regardless of channel, so the agent never has to ask "What happened when you called earlier?"

### Layout Structure:
The timeline sits on the far-left panel of the Agent Dashboard, functioning like an infinite scrolling social media feed, but for customer support interactions.

- **[Header]**: Customer Name, Lifetime Value (LTV), Current Churn Risk Score (e.g., 🔴 High, 🟢 Low).
- **[Scrollable Vertical Feed]**:
  - **Today, 10:15 AM** | 💬 **WhatsApp Icon** 
    - *Customer*: "Where is my refund for order #1234?"
    - *AI Bot*: "I see your return is processing. It should reflect in 3-5 days."
    - *Intent Tag*: `[Refund Status]` | *Sentiment*: `[Neutral]`
  - **Yesterday, 4:30 PM** | 📞 **Voice Icon**
    - *Summary (Auto-generated by AI)*: Customer called to initiate return for order #1234 because the shoes were too small. Agent approved return label.
    - *Length*: 03m 12s | *Link to Audio Recording*
    - *Intent Tag*: `[Return Request]` | *Sentiment*: `[Negative]`
  - **Last Week, Monday** | 📧 **Email Icon**
    - *Customer*: "Do you ship to Canada?"
    - *Agent (Sarah)*: "Yes, standard shipping takes 5-7 days."
    - *Intent Tag*: `[Shipping Inquiry]` | *Sentiment*: `[Positive]`

### Interactive Elements:
- **Filters**: Toggles to show only Voice, or only unresolved threads.
- **Search Bar**: Let agents search for keywords like "refund" across all historical channel data.
