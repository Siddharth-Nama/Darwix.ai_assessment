## User Stories
- **As a Customer**, I want to seamlessly switch from a WhatsApp conversation to a Voice call without having to re-explain my issue to the new agent.
- **As a Customer**, I want my routine requests (e.g., checking order status, processing a simple return) to be handled instantly by AI without waiting in a queue.
- **As a Support Agent**, I want to see a unified timeline of all previous interactions the customer has had with our brand across all channels so I can understand the full context.
- **As a Support Agent**, I want an AI Copilot to suggest draft responses based on the customer's sentiment and issue, so I can resolve tickets faster and with less typing.
- **As a CX Manager**, I want a dashboard that displays real-time sentiment analysis and churn risk for ongoing interactions so I can proactively intervene on escalated cases.

## Key Features (MVP vs Future State)

### MVP (Minimum Viable Product) Features
1. **Unified Omnichannel Inbox**: Aggregates Web Chat, WhatsApp, and Email into a single interface for agents.
2. **Real-time Intent & Sentiment Tagging**: AI models analyze incoming messages to tag them with an intent (e.g., "Refund Request") and sentiment score (Positive/Neutral/Negative/Urgent).
3. **Smart Routing**: Routes urgent or high-value customer interactions to the best available human agent based on the tagged intent.
4. **Agent AI Copilot**: Suggests context-aware responses and next best actions to human agents in real-time using historical data.

### Future State Features
1. **Real-time Voice AI**: Integration of speech-to-text text-to-speech to handle live inbound voice calls using the same underlying LLM logic.
2. **Autonomous Action Execution**: The AI automatically processes refunds, changes bookings, or updates account details without any human agent approval (once confidence thresholds are met).
3. **Proactive Outreach**: The AI anticipates customer needs based on predictive analytics and reaches out *before* the customer even initiates contact.
