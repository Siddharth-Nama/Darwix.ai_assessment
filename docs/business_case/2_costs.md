## 2. Cost Savings Breakdown

A concrete model for a mid-market e-commerce company handling **100,000 support interactions per month**:

### Current State (Before Platform)
| Category                          | Value             |
|-----------------------------------|-------------------|
| Monthly Interactions              | 100,000           |
| Human-handled (100%)              | 100,000           |
| Avg cost per human-handled ticket | $4.00             |
| **Total Monthly Support Cost**    | **$400,000**      |

### Future State (After Platform — 30% AI Deflection)
| Category                                   | Value             |
|--------------------------------------------|-------------------|
| AI-Deflected Interactions (30%)            | 30,000            |
| Cost per AI-handled interaction            | $0.15             |
| AI handling cost                           | $4,500            |
| Remaining human-handled interactions       | 70,000            |
| AHT Reduction of 20% → Cost per ticket     | $3.20             |
| Human handling cost                        | $224,000          |
| **Total Monthly Support Cost (After)**     | **$228,500**      |

### Net Monthly Savings
> **$400,000 − $228,500 = $171,500 per month saved**

### Annual Savings
> **$171,500 × 12 = $2,058,000 per year**

This alone justifies the investment for a single enterprise client.
